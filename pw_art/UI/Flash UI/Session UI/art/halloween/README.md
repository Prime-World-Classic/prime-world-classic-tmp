# Хэллоуинский скин интерфейса боя

Образцы: `_reference/` (текущие картинки из `main.fla` в исходном размере и примеры стиля `example_*.webp`).
Готовые картинки класть в `generated/` под именами из таблицы.

Общие требования:
- PNG **с прозрачным фоном**. Если генератор не умеет прозрачность — однотонный фон `#00FF00` (ярко-зелёный), вырежу сам.
- Размер — не меньше указанного (лучше больше). Уменьшу и нарежу сам: в игре картинка идёт в 2× к текущему размеру (под 2K).
- Без текста на картинках (надписи рисует игра).
- Палитра как в примере: тёмное фиолетово-коричневое дерево, оранжевое свечение, паутина, тыквы.
